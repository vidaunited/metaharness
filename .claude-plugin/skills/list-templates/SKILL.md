# list-templates

Lists every harness template `create-agent-harness` can scaffold from.

The live source of truth is `packages/create-agent-harness/templates/catalog.json`
(generated by `gen-templates.mjs`); `npx metaharness --list` prints it. The
table below mirrors that catalog — 20 templates.

## Templates today (20)

Scaffold one with `npx metaharness <name> --template <id> --host <host>`
(`minimal` is the default template; `claude-code` the default host).

## Hosts every template supports (10)

Every template renders for every host in the canonical catalog
(`HOSTS` in `packages/create-agent-harness/src/index.ts`); pass several
`--host` flags for a multi-host harness (GH #10).

| Host id | Adapter package |
|---|---|
| `claude-code` | `@metaharness/host-claude-code` |
| `codex` | `@metaharness/host-codex` |
| `pi-dev` | `@metaharness/host-pi-dev` |
| `hermes` | `@metaharness/host-hermes` |
| `openclaw` | `@metaharness/host-openclaw` |
| `rvm` | `@metaharness/host-rvm` |
| `copilot` | `@metaharness/host-copilot` |
| `opencode` | `@metaharness/host-opencode` |
| `github-actions` | `@metaharness/host-github-actions` |
| `prime-agent` | `@metaharness/host-prime-agent` |

`github-actions` is the non-interactive host (ADR-033); `prime-agent` is
skills-based with no MCP (ADR-247).
